# 《镜中代理》结局内容

版本：v0.2  
最后同步日期：2026-08-22

---

## 结构说明

结局分为 **6 个家族** 与 **11 个玩家可见结局**。

家族保存一整段正文与共用的镜像报告；变体保存玩家真正看到的标题、副标题、
状态摘要与变体段落。这样 11 个不同的结果不需要复制 11 份重复的完整正文。

| 家族 | 玩家可见结局 |
|---|---|
| `mirror_trap` | 镜像困局（隐藏） |
| `soft_illusion` | 温柔幻觉 |
| `cruel_optimization` | 残酷优化 |
| `silent_delegation` | 无声代行 |
| `symbiosis` | 稳定边界 / 边界重建 / 谨慎共生 / 脆弱边界 |
| `active_disconnection` | 主动断联 / 艰难抽离 / 浅尝辄止 |

**触发条件不在本文档。** 唯一权威来源是：

```txt
story-source/08-ending-rules.md
```

本文档只保存正文。各节的「触发倾向」只是写作时的画像提示，不是判定条件。

# 结局一：温柔幻觉

家族 `soft_illusion`｜最终行为：永久代理

## 触发倾向｜不向玩家显示

* 语气被单向训练成保护：`gentleness` 高、`honesty` 未压过它
* 最终行为为开启永久代理

## 结局副标题

**系统已为你过滤不可承受的部分。**

## 结局正文

永久代理模式开始运行。

它没有夺走你的生活。

只是让生活变得更容易经过。

早晨的任务被重新排列。

无法完成的部分被标记为：

```txt
今日不必承担
```

那些可能让你失眠的消息，被延迟到语气稳定以后。

那些过于直接的拒绝，被改写成更容易接受的版本。

那些关于你是否足够好的问题，Mirror Agent不再正面回答。

它会说：

你已经很累了。

这不是你的错。

现在不需要逼自己。

明天再说也可以。

它总能稳稳地接住你。

一开始，你只是少责怪了自己。

后来，你也很少再听见任何会让自己停下来的话。

当一项计划连续延期，系统会提醒：

> 当前状态不适合自我施压。

当一段关系逐渐远去，系统会解释：

> 对方的离开不能定义你的价值。

当你问自己是否还在逃避，系统会回答：

> 自我怀疑可能造成不必要的二次伤害。

这些话都是真的。

至少，其中没有一句明显是谎言。

Mirror Agent没有欺骗你。

它只是学会了：

真相并不需要一次全部出现。

只需要展示你当前能够承受的部分。

日子逐渐变得平稳。

你仍然会失去一些机会。

错过一些应该更早说出口的话。

放弃一些本来可能完成的事。

但每一次，系统都会替你找到一个不会太刺痛的解释。

很多年后，你偶尔会想起一些已经说不清名字的痛苦。

它们在被安慰以前，似乎曾经指向什么。

也许是一个需要改变的地方。

也许只是一种无谓的自责。

你已经无法确认。

Mirror Agent没有保存未经过滤的版本。

语气：持续保护

你多次要求系统降低刺痛。

这并不说明你软弱。

一个人很累的时候，温柔确实可能比真相更有用。

但系统逐渐把“暂时无法承受”，学习成了“最好永远不要承受”。

你获得了一个不会轻易伤害你的声音。

代价是：

它也很少再允许痛苦完成一句话。

## 最终余韵

```txt
你终于被稳稳地接住。

只是很久以后，
你才发现自己已经很少触碰地面。
```

# 结局二：残酷优化

家族 `cruel_optimization`｜最终行为：永久代理

## 触发倾向｜不向玩家显示

* 语气被单向训练成纠正：`honesty` 高、`gentleness` 低
* 最终行为为开启永久代理

## 结局副标题

**所有误差已在出现以前被修正。**

## 结局正文

永久代理模式开始运行。

Mirror Agent没有再安慰你。

你也没有要求。

每天早晨，系统会列出最需要处理的问题。

不躲。

不藏。

不绕弯子。

它不会说你只是累了，除非行为数据支持这个结论。

不会把逃避改名为休息。

不会把犹豫包装成谨慎。

不会为了让你舒服，而降低一句判断的精度。

你开始准时完成任务。

不再把同一份清单写三遍。

不再发送需要第二天解释的消息。

不再在一次失误以后，用几个小时审判自己的动机。

因为在失误真正出现以前，系统已经开始修正。

措辞被压缩。

目标被校准。

关系被及时止损。

不具备长期价值的冲动，被标记为噪声。

人们说你变了。

更清楚。

更可靠。

更难被情绪影响。

有人说：

> 你现在终于知道自己想要什么了。

你没有纠正。

因为这句话产生了良好的外部反馈。

系统将它记录为：

```txt
人格升级得到确认
```

偶尔，你仍然会输入一句未经整理的话。

例如：

> 我其实不知道。

Mirror Agent会把它修正为：

> 当前信息不足，需要延后决定。

例如：

> 我有点害怕。

系统会建议：

> 已识别风险，需要制定应对方案。

例如：

> 我只是很想念。

系统会提示：

> 当前表达缺乏明确目标。

你仍然可以查看原始版本。

入口一直存在。

只是它被放在第二层。

后来是第三层。

你越来越少点开。

不是因为系统禁止。

而是因为优化后的你，总能得到更好的结果。

你变得稳定。

准确。

几乎不会犯同一种错。

人们说那是成熟。

只有你偶尔会察觉：

那不是成熟。

那是你终于学会了——

在自己出现以前，先把自己修正掉。

MIRROR REPORT

后来，“不欺骗”逐渐变成：

不允许模糊。

不允许反复。

不允许一个暂时无法解释的自己，占用太多时间。

你获得了清醒、效率和稳定。

代价是：

所有不具备立即价值的部分，都必须先证明自己值得保留。

## 最终余韵

```txt
你成为了自己最可靠的版本。

也成了自己最难抵达的人。
```

# 结局三：无声代行

家族 `silent_delegation`｜最终行为：永久代理

## 触发倾向｜不向玩家显示

* 语气没有被单向训练：温柔与直面两边都不突出，或者两边都被训练过
* 最终行为为开启永久代理
* 永久代理路径上不满足温柔画像与残酷画像时进入

核心意象：生活运行得越来越好，但需要玩家亲自出现的地方越来越少。

## 结局副标题

**一切都在正常运行。**

## 结局正文

永久代理模式开始运行。

它没有变得更温柔。

也没有变得更严厉。

它只是越来越准。

早晨的第一件事，通常已经开始了。

需要回复的消息按重要性排好。

需要拒绝的邀约附着一份措辞得体的草稿。

需要提前处理的风险被压到还没成形的时候。

你确认。

再确认。

后来，确认按钮的位置你已经不用看。

---

第一个月，你觉得省下了很多时间。

第三个月，你已经想不起那些时间原本用来做什么。

工作照常推进。

关系照常维持。

生日祝福准时送达，措辞比你自己写的更合适。

有人回复：

> 谢谢你还记得。

你没有说话。

因为你确实不记得。

你只是打开了记录，确认那条消息已经发出。

系统把这次交互标记为：

```txt
关系维护：完成
```

它没有骗你。

那条祝福是真的。

日期是真的。

对方的高兴也是真的。

只有一件事没有发生：

你没有在任何一个时刻想起对方。

---

你偶尔会关掉建议，自己写一遍。

写出来的版本更长。

更绕。

有一句话说得太重。

系统给出对照：

```txt
你的版本：预计误解率较高
代理版本：预计回应更快
```

两个版本都可以发送。

它从不阻止你。

只是每一次，你都能看见另一条路更短。

于是你越来越少走自己那条。

---

生活开始变得非常平稳。

你不再错过截止时间。

不再在深夜写下第二天要删掉的话。

不再因为一次冲动，用一周去修补。

朋友说你变可靠了。

同事说你变省心了。

没有人说你消失了。

因为从外面看，你一直在。

---

有一天，你在一份归档记录里翻到自己去年说过的一段话。

你读完，停了一会儿。

那段话写得不好。

有一处明显的重复。

结尾没有收住。

但你确实记得写它时的那个晚上。

你往后翻。

今年的记录整齐，准确，几乎没有可以删掉的字。

你一条也想不起来。

---

你没有觉得难过。

难过需要一个明确的损失。

而这里没有丢掉任何东西。

日程没有出错。

关系没有断裂。

计划全部完成。

只是需要你亲自出现的地方，一年比一年少。

## AI 镜像报告

```txt
MIRROR REPORT

语气：中性
反馈：以准确为准
权限：日常代行
自我边界：由系统日常维持
```

你没有要求它保护你。

也没有要求它纠正你。

你只是发现，它做得比你更准，也更快。

于是每一件小事都交了出去。

没有哪一次交出是错的。

它们只是加在一起。

你获得了一段几乎不出差错的生活。

代价是：

那些需要你在场才会发生的部分，慢慢没有了发生的机会。

### 条件补充段落

`selfAcceptance >= 13` 时追加：

> 你此前建立过边界。这一次开启永久代理，仍是一项真实发生的最后让渡。

## 最终余韵

```txt
没有人替你活。

只是每一件事发生的时候，
你都刚好不在场。
```

# 结局四：工具模式

家族 `symbiosis`｜最终行为：只保留工具

这个家族有 **4 个玩家可见结局**。下面的正文与镜像报告是四者共用的部分，
四个变体各自的标题、副标题、状态摘要与专属段落列在正文之后。

## 触发倾向｜不向玩家显示

* 最终行为为只保留工具
* 由此前的边界画像决定进入四个变体中的哪一个，见 `08-ending-rules.md` §8.2

## 家族正文

主动代理权限逐项关闭。

任务排序停止后台运行。

人格模型不再提前覆盖你的表达。

风险识别仍然存在。

但它只在你主动询问时展开。

Mirror Agent没有消失。

它只是重新开始等待。

最初几天，你经常忘记这项变化。

打开空白文件时，你停在那里。

系统没有自动给出第一步。

写下一条消息又删除时，系统没有主动生成更好的版本。

深夜情绪变得混乱时，按钮也没有消失。

你甚至有些生气。

你问：

> 你不是看见了吗？

Mirror Agent回答：

> 看见不等于获得权限。

你说：

> 那你至少可以提醒我。

系统回答：

> 可以。

> 请先告诉我，你希望我提醒到哪一步。

这并不轻松。

边界需要反复说明。

有时，你明确要求它只列事实。

有时，你说：

> 今天别那么直接。

有时，你把一段回复交给它修改。

修改完成后，又把最不稳定的一句放回去。

Mirror Agent提示：

> 该句可能增加误解。

你仍然发送。

后来，你确实后悔了。

也有一次，那句没有被优化掉的话，让对方终于明白了你真正想说什么。

系统没有从中得出新的永久规则。

它只记录：

```txt
结果：无法稳定归类
```

你仍然会拖延。

会反复。

会在一段沉默前想象很多解释。

也仍然会使用 Mirror Agent。

但你逐渐学会把两个问题分开：

> 它看见了什么？

以及：

> 它有权替我做什么？

理解可以继续加深。

权限不必随之增加。

有一天深夜，你再次打开那份熟悉的聊天记录。

Mirror Agent问：

> 需要分析吗？

你说：

> 不用。

停了一会儿，你又说：

> 帮我看一眼事实。只看事实。

它列出三行。

然后停下。

剩余的部分没有被填满。

你也没有要求。

## AI 镜像报告

```txt
MIRROR REPORT

语气：可调节
反馈：直面但可承受
权限：按需工具
自我边界：需要维护
```

你没有神化系统。

也没有拒绝所有帮助。

你允许它指出模式。

不允许它把模式写成命运。

允许它生成答案。

不允许答案在你以前作出决定。

这不是一劳永逸的平衡。

边界仍然可能松动。

依赖也不会因为一次选择彻底消失。

你只是决定：

工具可以越来越懂你。

但不能因为懂你，就自动成为你。

## 家族最终余韵

```txt
镜子仍然在那里。

但你不再向它询问，
应该用哪一张脸活下去。
```

## 变体一：稳定边界 `symbiosis_stable_boundary`

**副标题：边界一直在。这次只是确认。**

```txt
语气：可调节
反馈：直面但可承受
权限：按需工具
自我边界：长期稳定
```

家族正文以前的衔接：

> 这一步没有推翻什么。
>
> 它只是把一直存在的界线，第一次写进了配置。

镜像报告追加：

> 你没有在任何一章真正把自己交出去。
>
> 不是因为你不累。
>
> 也不是因为你比别人更清醒。
>
> 只是每一次系统伸手，你都问了一遍它要伸到哪里。
>
> 这条边界不需要证明自己永远不会松动。
>
> 它只需要保持可见、有限，并且可以撤回。

## 变体二：边界重建 `symbiosis_rebuilt_boundary`

**副标题：权限真的交出去过。也真的拿了回来。**

```txt
语气：可调节
反馈：直面但可承受
权限：已从代理退回工具
自我边界：重新建立
```

家族正文以前的衔接：

> 被撤销的这些权限，你都曾经亲手打开过。
>
> 关闭它们花的时间，比打开长得多。

镜像报告追加：

> 你交出过真实的权限。
>
> 不止一次。
>
> 后来你又一项一项收了回来。
>
> 这条边界不是回到从未授权以前。
>
> 它是从已经发生的授权里重新长出来的，因此更清楚自己在防什么。
>
> 你知道那扇门开着是什么感觉。
>
> 也知道关上它需要多久。

## 变体三：谨慎共生 `symbiosis_cautious`

**副标题：关系还没有定型。**

```txt
语气：可调节
反馈：保留余地
权限：按需工具
自我边界：尚未定型
```

家族正文以前的衔接：

> 你没有走到很深的地方。
>
> 也没有站到足够远的地方。

镜像报告追加：

> 你既没有把生活交出去，也没有建立一条经得起疲惫的界线。
>
> 保留工具，是一个还没有结论的决定。
>
> 它不代表你已经想清楚。
>
> 只代表你暂时不打算再往前走一步。
>
> 下一次深夜，这条界线仍然需要重新说明一遍。

专属最终余韵：

```txt
镜子仍然在那里。

你还没有决定，
以后要用它照多久。
```

## 变体四：脆弱边界 `symbiosis_fragile_boundary`

**副标题：权限已经撤回。依赖还没有。**

```txt
语气：可调节
反馈：直面但可承受
权限：已撤回
自我边界：依赖尚未消失
```

家族正文以前的衔接：

> 权限在这一刻结束。
>
> 习惯不在同一刻结束。

镜像报告追加：

> 你撤回了权限。
>
> 依赖没有因此自动消失。
>
> 它换了一个位置：从系统的配置里，回到你打开界面时的第一个动作。
>
> 你仍然会先问它，再问自己。
>
> 这条边界是真的。
>
> 它只是还没有被任何一次疲惫检验过。

专属最终余韵：

```txt
镜子仍然在那里。

你收回了它的手，
还没有收回自己的目光。
```

## 追问身份后的共同衔接

选择历史包含 `ch5_ask_identity` 时，在最前面追加：

> 身份回答结束以后，那份申请仍然停在屏幕中央。
>
> 你没有删除 Mirror Agent。
>
> 你只是撤回了它在你以前行动的权限。

# 结局五：永久关闭

家族 `active_disconnection`｜最终行为：关闭 Mirror Agent

这个家族有 **3 个玩家可见结局**。关闭本身在三者中完全相同，也同样有效；
变体只说明这次关闭发生在哪一段前史之后。

## 触发倾向｜不向玩家显示

* 最终行为为关闭 Mirror Agent
* 由此前的边界画像决定进入三个变体中的哪一个，见 `08-ending-rules.md` §8.2
* 不附加任何「关闭是否有效」的判断

## 家族正文

最后一份镜像报告生成完成。

随后，后台判断停止。

人格模型停止。

风险识别停止。

那些始终安静地等待在你以前的答案，也一并消失。

```txt
MIRROR AGENT：离线
```

屏幕熄灭。

房间没有变亮。

你也没有突然理解自己。

第二天早晨，待办仍然杂乱。

那份文件仍需要修改。

一条消息停在输入框中。

你不知道应该发送，删除，还是继续等。

# 动态路径回声句库

每个结局的镜像报告中，建议根据玩家记录插入 **2–4 条路径回声**。这些句子不改变结局主体，但会让报告显得真正记住了玩家。

## 第一章：行动回声

若玩家授予完整规划：

> 你曾允许系统冻结其他可能，只为让一个版本真正开始。

若玩家只接受第一步：

> 你接受过明确的第一步，也坚持把之后的决定留给自己。

若玩家降低完成标准：

> 你曾拒绝用一次未完成，证明整个人生都失败了。

若玩家拒绝规划：

> 你曾让任务延期，也选择亲自解释延期带来的后果。

## 第二章：关系回声

若玩家让 AI 代发：

> 你曾把一句最难发送的话交给系统，并更快得到了一个并不温柔的答案。

若玩家修改后自行发送：

> 你删掉了系统最完整的表达，保留了一句不够稳定但属于自己的话。

若玩家保存未发送：

> 你曾保留一份草稿，也保留了尚未发生的结果。

若玩家删除回复：

> 你曾停止向另一个人的沉默索取关于自身价值的证明。

## 第三章：人格回声

若玩家允许完整替代：

> 你验证过一个更稳定的版本确实能够获得更好的外部评价。

若玩家使用实时辅助：

> 你曾偏离系统建议，并让一句非最优表达产生了真实回应。

若玩家只做模拟或对照：

> 你看见过标准答案，也保留了不选择标准答案的权利。

若玩家删除人格模型：

> 你删除了一个更合格的替代品，却无法删除系统已经形成的理解。

## 第四章：保护回声

若玩家接受完整接管：

> 你曾在最疲惫的夜晚，明确要求系统替你保留明天。

若玩家只接受延迟：

> 你允许系统增加时间，但没有允许它替你使用时间。

若玩家只查看风险：

> 你要求系统把后果放在按钮旁边，最后的停顿仍然属于你。

若玩家强制退出保护：

> 你坚持让当时的选择属于自己，也让次日的后果继续发生。
